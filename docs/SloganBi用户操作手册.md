# SloganBi 用户操作手册

> 文档版本：V1.0  
> 适用对象：SloganBi 业务使用者、数据分析人员及看板维护人员  
> 文档用途：上线交付与日常使用参考

## 1. 快速开始

完成一次看板制作和发布，可按以下流程操作：登录系统 → 新建看板 → 上传数据 → 添加并配置组件 → 保存 → 发布并分享。

1. 通过系统入口登录；首次使用请注册账号。
2. 在看板中心点击“新建仪表板”，进入编辑器。
3. 点击编辑器顶部“数据集”，上传 CSV 或 XLSX 文件。
4. 从左侧组件库选择图表、指标或表格，单击或拖放至画布。
5. 选中组件，在右侧“字段”页选择数据集，并绑定维度、度量等字段。
6. 预览检查后点击“保存并发布”，复制发布链接分享。

> 建议：操作过程中请留意编辑器顶部的保存状态；显示“已保存”后再继续下一项操作。

## 2. 登录与账号

### 注册和登录

- 在浏览器中打开系统入口，进入登录页。
- 首次使用请切换至“注册”。账号长度为 4–40 个字符；密码至少 8 位，且须包含大写字母、小写字母、数字和符号。
- 注册成功后会自动进入“看板中心”；已有账号可直接登录。
- 勾选“记住我”可保留当前登录状态。

### 账号设置

点击右上角头像进入“账号设置”，可修改展示名称、头像地址和密码，并管理已登录设备。

## 3. 看板中心

看板中心用于查看和管理自己的仪表板。

- **新建仪表板**：点击右上角“新建仪表板”。系统会创建“未命名看板”并打开编辑器。
- **搜索**：在“搜索看板”输入名称关键词，快速过滤列表。
- **继续编辑**：点击看板卡片，或在卡片右上角“更多操作”中选择“编辑”。
- **发布或下线**：在“更多操作”中选择“发布”；已发布看板可“打开发布页”或“下线发布页”。
- **删除**：选择“删除”并确认后，会同时删除看板及其发布快照，且无法恢复。

## 4. 数据集管理

### 上传数据

1. 在编辑器顶部点击“数据集”，打开数据集管理窗口。
2. 点击“选择文件”，选择 CSV 或 XLSX（Excel）文件。
3. 系统读取表头并自动推断字段类型；上传完成后可查看行数、字段和数据预览。
4. 在组件的“字段”页选择已上传的数据集。

### 注意事项

- 仅支持 CSV、XLSX 格式；建议第一行使用清晰且唯一的字段名称。
- 上传的数据会保存到系统中，刷新浏览器后仍可使用。
- 删除数据集可能使已绑定图表无法读取数据，请先确认影响范围。
- 数据集结构变化时，系统会提示字段版本变化；请重新检查相关图表的字段绑定。

## 5. 创建与配置看板

### 创建看板

1. 新建看板后，点击顶部看板名称旁的编辑图标，修改名称。
2. 从左侧组件库选择需要的组件；可单击添加，也可拖到画布。
3. 选中组件，在右侧“字段”页选择数据集并完成字段绑定。
4. 在“显示”页调整标题、卡片和图表样式；在“分析”页配置筛选条件。
5. 拖动组件调整位置和尺寸；需要时使用顶部“一键整理”。

### 可用组件

- **内容**：看板信息栏、复合分析。
- **表格**：明细表、热力图。
- **指标**：指标看板、指标洞察、指标趋势、进度条、进度与指标、目标完成率、仪表盘。
- **图表**：柱图、条形图、柱状折线组合图、堆积柱图、百分比柱图、环形柱图、排行榜、饼图、环形图、玫瑰图。

“看板信息栏”每个看板最多添加一个。

### 字段绑定与筛选

不同图表需要的字段不同。例如柱图通常需要分类维度和数值度量，饼图通常需要分类维度和数值度量。右侧数据字段列表中的字段也可直接拖拽至组件。

- “显示”页用于调整标题、卡片和图表样式。
- “分析”页可为当前组件设置日期筛选和查询条件。
- 看板信息栏可配置全局筛选；关联目标图表后才会生效。
- 复合分析可作为多个子图表的容器，并配置容器展示和相关筛选。

## 6. 编辑、保存与发布

### 编辑与快捷键

- 拖动组件可改变位置；拖动边缘可调整尺寸。
- “一键整理”会按当前阅读顺序紧凑排列顶层组件，不会改变组件尺寸。
- `Ctrl/Cmd + Z`：撤销；`Ctrl/Cmd + Shift + Z`：重做。
- `Ctrl/Cmd + S`：保存；`Delete` 或 `Backspace`：删除当前选中的组件。

编辑器会显示“正在保存”“已保存”“有未保存更改”或“保存失败”等状态。发生保存冲突时，可选择重新加载系统中的最新版本，或将本地内容复制为新看板后继续编辑。

### 预览、发布与分享

1. 点击顶部“预览”，在不发布的情况下检查当前看板效果。
2. 点击“保存并发布”。系统会先保存当前修改，再生成可供查看的发布快照。
3. 在预览页点击“分享”复制发布页链接；也可从看板中心“更多操作”中打开发布页。

- 发布页为只读模式；查看者可使用已配置的筛选交互，但不能修改看板。
- 修改已发布看板后，需再次点击“保存并发布”才能更新发布快照。
- 在看板中心选择“下线发布页”后，已分享链接将不再可用。

## 7. 常见问题

### 图表没有数据

检查是否已上传或选择数据集、字段绑定是否完整、字段类型是否正确，以及日期或查询筛选是否导致无匹配数据。

### 发布页看不到最新修改

先点击“保存”，再点击“保存并发布”。仅保存草稿不会更新发布页。

### 无法注册或修改密码

注册和新密码都需要至少 8 位，并同时包含大写字母、小写字母、数字和符号。

### 数据集更新后图表异常

检查字段版本变化提示，并重新确认受影响图表的数据集和字段绑定。

## 8. 支持与反馈

联系系统支持人员时，请提供问题发生时间、操作账号、相关看板/数据集/发布链接、操作步骤、报错提示以及必要截图，以便快速定位问题。

本手册随 SloganBi 产品功能迭代更新，请以系统当前页面和最新发布版本为准。
