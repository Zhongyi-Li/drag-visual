# ZHBi 简易使用手册

本文面向业务使用者，介绍从登录到发布看板的基本操作。

## 1. 进入系统

在浏览器中打开系统入口，进入登录页面。

首次使用请切换到“注册”：

- 账号长度为 4–40 个字符；
- 密码至少 8 位，且须包含大写字母、小写字母、数字和符号；
- 注册成功后会自动进入“ZHBi 看板中心”。

已有账号可直接登录。“记住我”会保留当前登录状态。

## 2. 看板中心

看板中心用于管理自己的仪表板。

- **新建仪表板**：点击右上角“新建仪表板”。系统会创建一个“未命名看板”并打开编辑器。
- **搜索**：在“搜索看板”输入名称关键词，快速过滤列表。
- **继续编辑**：点击看板卡片，或点卡片右上角“更多操作”中的“编辑”。
- **发布或下线**：在“更多操作”中选择“发布”；已发布的看板可以“打开发布页”或“下线发布页”。
- **删除**：在“更多操作”中选择“删除”，确认后会同时删除看板及其发布快照，且不能恢复。
- **账号设置**：点击右上角头像，进入“账号设置”，可修改展示名称、头像地址、密码，并管理已登录设备。

## 3. 创建一个看板

建议按以下顺序完成：

1. 新建看板后，点击顶部看板名称旁的编辑图标，修改名称。
2. 点击顶部“数据集”，上传并检查数据。
3. 从左侧组件库选择需要的图表；可单击添加，也可拖到画布。
4. 选中画布中的组件，在右侧“字段”页完成数据绑定。
5. 在右侧“显示”和“分析”页调整呈现方式与筛选条件。
6. 拖动组件调整位置和尺寸；需要时点击顶部“一键整理”。
7. 点击“保存”，确认看板已保存；满意后点击“保存并发布”。

## 4. 数据集管理

在编辑器顶部点击“数据集”打开数据集管理窗口。

### 上传数据

1. 点击“选择文件”。
2. 选择 CSV 或 XLSX（Excel）文件。
3. 系统读取表头并自动推断字段类型，上传完成后会显示行数。
4. 在窗口中选中数据集，可查看字段和数据预览。

上传的数据会保存到系统中，刷新浏览器后仍可在图表的“数据集”下拉框中使用。

### 注意事项

- 文件仅支持 CSV、XLSX 格式。
- 删除数据集可能使已绑定该数据集的图表无法读取数据，请先确认影响范围。
- 若数据集结构发生变化，系统会提示字段版本变化；请重新检查相关图表的字段绑定。

## 5. 添加和配置组件

### 可用组件

左侧组件库目前提供以下主要类型：

- 内容：看板信息栏、复合分析；
- 表格：明细表、热力图；
- 指标：指标看板、指标洞察、指标趋势、进度条、进度与指标、目标完成率、仪表盘；
- 图表：柱图、条形图、柱状折线组合图、堆积柱图、百分比柱图、环形柱图、排行榜、饼图、环形图、玫瑰图。

“看板信息栏”每个看板最多添加一个。

### 绑定数据

1. 在画布中单击一个组件。
2. 在右侧配置面板的“字段”页，选择“数据集”。
3. 根据组件类型选择维度、度量、日期、目标等字段。也可以从右侧数据字段列表拖拽字段到组件。
4. 图表会按所选字段自动刷新。不同图表需要的字段不同，例如柱图通常需要维度和数值度量，饼图需要分类维度和数值度量。

### 调整显示和分析

- **显示**页可设置标题、卡片和图表样式；部分图表还支持辅助展示设置。
- **分析**页可为当前组件设置日期筛选和查询条件。
- 选中“看板信息栏”后，可配置标题、描述和全局筛选；全局筛选需关联目标图表后才会生效。
- “复合分析”可作为多个子图表的容器，并配置容器展示和相关筛选。

## 6. 编辑操作与快捷键

- 拖动组件可改变位置；拖动边缘可调整尺寸。
- 顶部“一键整理”会按当前阅读顺序紧凑排列顶层组件，不会改变组件尺寸。
- 顶部的撤销、重做按钮可恢复或重做编辑操作。
- `Ctrl/Cmd + Z`：撤销。
- `Ctrl/Cmd + Shift + Z`：重做。
- `Ctrl/Cmd + S`：保存看板。
- `Delete` 或 `Backspace`：删除当前选中的组件。

编辑器会显示“正在保存”“已保存”“有未保存更改”或“保存失败”等状态。发生保存冲突时，可选择重新加载系统中的最新版本，或将本地内容复制为新看板后继续编辑。

## 7. 预览、发布与分享

- **预览**：编辑器顶部点击“预览”，在不发布的情况下检查当前看板的效果；预览页可返回继续编辑。
- **发布**：点击“保存并发布”。系统会先保存当前修改，再生成一份可供查看的发布快照。
- **分享**：在预览页点击“分享”，可复制发布页链接；也可从看板中心的“更多操作”打开发布页。
- **发布页**：发布页为只读模式，查看者可使用已配置的全局筛选、日期筛选等交互，但不能修改看板。
- **更新已发布看板**：修改后再次点击“保存并发布”，即可用最新内容更新发布快照。
- **下线**：在看板中心的“更多操作”选择“下线发布页”，已分享的发布链接将不再可用。

## 8. 常见问题

### 图表没有数据

依次检查：是否已上传或选择数据集、字段绑定是否完整、字段类型是否正确、是否配置了日期或查询筛选导致无匹配数据。

### 发布页看不到最新修改

请在编辑器中先点击“保存”，再点击“保存并发布”。仅保存草稿不会更新发布页。

### 无法注册或修改密码

注册和新密码都需要至少 8 位，并同时包含大写字母、小写字母、数字和符号。
